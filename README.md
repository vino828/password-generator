🔐 Password Generator

A simple, secure, and attractive Password Generator web application that allows users to create strong and random passwords instantly.

✨ Features

- 🔑 Generate strong random passwords
- 🔢 Choose password length
- 🔠 Include uppercase letters
- 🔡 Include lowercase letters
- 🔢 Include numbers
- 🔣 Include special characters
- 📋 Copy generated password with one click
- 📱 Responsive and user-friendly design
- ⚡ Fast and easy to use

🛠️ Technologies Used

- HTML5 – Structure of the application
- CSS3 – Styling and responsive design
- JavaScript – Password generation and functionality

🚀 How to Use

1. Open the Password Generator website.
2. Select your preferred password length.
3. Choose the character types you want to include.
4. Click the Generate Password button.
5. Copy the generated password and use it wherever required.

🎯 Project Objective

The main objective of this project is to create a convenient tool for generating strong and random passwords while practicing HTML, CSS, and JavaScript concepts.

🔒 Security Note

The generated passwords are created locally in the browser. Avoid sharing your passwords with others and use unique passwords for different accounts.
